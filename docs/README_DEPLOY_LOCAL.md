# التشغيل المحلي (Windows)

## المتطلبات
- Python 3.12. وقت التثبيت علّم ✅ **Add python.exe to PATH**.
- Edge أو Chrome.
- إنترنت أول مرة بس، عشان المكتبات تتنزّل.

## أول مرة
1. شغّل `setup.bat`. بيعمل الآتي:
   - بيئة Python معزولة (`backend\.venv`).
   - تثبيت المكتبات.
   - قاعدة البيانات.
   - أول حساب **Super Admin**، وكلمة المرور بتكتبها انت. مفيش حسابات تجريبية.
   - مفتاح تشفير الأسرار `ITADM_SECRET_KEY`، بيتكتب لوحده في `backend\.env`.
2. **اعمل نسخة من `backend\.env` في مكان آمن**، زي فلاشة أو مدير باسوردات. لو المفتاح ضاع، باسوردات الأجهزة وصلاحيات Google المشفّرة مش هتتقري تاني.
3. شغّل `run.bat`. بيفتح نافذتين:
   - **السيرفر:** على `http://127.0.0.1:8000/app.html`.
   - **الـ Worker:** للتنبيهات والمزامنة والسكريبتات.
4. ادخل وابدأ من **إدارة النظام**: الشركات (والبادئة والدباجة)، وبعدها المستخدمين.

## أماكن الملفات
| المسار | المحتوى |
|---|---|
| `backend\data\itadmin.db` | قاعدة البيانات (SQLite) |
| `backend\data\files\` | المستندات المرفوعة (اسم الملف هو المعرّف، والبصمة متسجلة) |
| `backend\data\workbooks\` | ملفات Excel المحلية المستخدمة كمصدر بيانات |
| `backend\data\backups\` | النسخ الاحتياطية |
| `%LOCALAPPDATA%\ITAdministration\secrets.enc.json` | الأسرار المشفّرة AES-256 (**خارج فولدر المشروع**) |
| `backend\.env` | مفتاح التشفير والإعدادات (متجاهل في Git) |

## النسخ الاحتياطي والاستعادة
- **نسخة:** من **إدارة النظام ← السجلات والنسخ الاحتياطي**، أو بالأمر `backend\.venv\Scripts\python -m app.cli backup`.
- **«تحقق»:** استعادة تجريبية حقيقية في مجلد مؤقت. بيطابق البصمات ويعمل integrity_check.
- **استعادة فعلية:** اقفل السيرفر والـ Worker، وبعدين `restore.bat <اسم النسخة>`. قبل الاستعادة بتتعمل نسخة من الوضع الحالي تلقائيًا.
- **انسخ مجلد `backups` وملف `secrets.enc.json` و`backend\.env` لمكان تاني.** النسخة اللي على نفس الجهاز مش حماية.

## التحقق بخطوتين (MFA)
كل مستخدم يفعّله لنفسه من **إدارة النظام ← المظهر والتخصيص**، بتطبيق Google Authenticator أو Microsoft Authenticator. لو حد ضيّع موبايله، المدير يعمل له «إعادة ضبط MFA» من صفحة المستخدمين.

## لو الجهاز اتقفل
- الـ Worker بيقف، والواجهة بتعلّم البيانات إنها «قديمة».
- استمارة Google بتفضل تستقبل طلبات، وبتتسحب أول ما الـ Worker يرجع.

## الاختبارات
- `run_tests.bat`: اختبارات السيرفر.
- `run_e2e.bat`: اختبار في متصفح حقيقي على قاعدة بيانات مؤقتة.

## الواجهة القديمة
`frontend/it.html` نسخة Demo قديمة بياناتها في المتصفح. نقل بياناتها للسيرفر بيتعمل من **المظهر والتخصيص ← نقل بيانات النسخة القديمة**: تجربة الأول، وبعدين التنفيذ.
