# ربط Google Sheets / Forms / Drive

> **الحالة الحالية:** الربط متبني ومتختبر على Sandbox وهمي بس. **مفيش اتصال حقيقي** لحد ما الشركة تعمل الخطوات دي. النظام مش هيعرض «✓ متصل» قبل أول مزامنة حقيقية ناجحة.

## الخيار 1: ملف Excel محلي (من غير Google)
1. **استيراد وتصدير Excel** ← نزّل القالب المناسب من «قوالب الشيتات الخمسة»، أو استخدم ملفك.
2. **الربط والأتمتة** ← على كارت الشيت دوس **⬆ ملف Excel** وارفع الملف.
3. دوس **↻ حدّث دلوقتي**. النظام بيقرا ويكتب في الملف نفسه:
   - التنسيق والقوائم المنسدلة والمعادلات بتفضل زي ما هي.
   - بياخد نسخة `.bak` قبل أول كتابة.
4. تقدر تنزّل النسخة الحالية في أي وقت من نفس الكارت.

## الخيار 2: Google Sheets أونلاين (قراءة وكتابة)
1. **Google Cloud Console** ← مشروع جديد ← فعّل **Google Sheets API** و**Google Drive API**.
2. **IAM ← Service Accounts** ← Create ← بعدين **Keys ← Add key ← JSON**. هينزل ملف JSON.
3. ارفع القوالب الخمسة على Google Drive، وافتح كل واحد كـ **Google Sheets** (File ← Save as Google Sheets).
4. شارك كل شيت مع إيميل الـ Service Account (`xxx@yyy.iam.gserviceaccount.com`) بصلاحية **Editor**.
5. في النظام:
   - **الربط والأتمتة ← الأسرار المشفّرة ← سر جديد:** الاسم مثلًا `google-sa`، والقيمة محتوى ملف الـ JSON كله. بعدها **امسح ملف الـ JSON من جهازك**.
   - على كل كارت ← **⚙ إعداد:** حط لينك الشيت، وطريقة الربط **Google Sheets**، واسم ملف الصلاحية `google-sa`، وعلّم «ربط تلقائي».
6. ثبّت مكتبات Google مرة واحدة:
   `backend\.venv\Scripts\pip install google-api-python-client==2.151.0 google-auth==2.36.0`
7. دوس **↻ حدّث دلوقتي**. لو نجحت، الكارت هيبقى **✓ متصل**.

## الخيار 3: لينك عادي (استيراد بس)
لو الشيت متشارك «Anyone with the link — Viewer»، تقدر تستورده من **استيراد ⬆ ← لينك Google Sheet**. ده قراءة بس، ومفيش كتابة من النظام للشيت.

## استمارة التقديم (Google Form + QR)
1. افتح شيت M03 كـ Google Sheets، وخد الـ ID بتاعه.
2. افتح `master_package/google_setup/Create_Application_Form.gs` في Apps Script، وحط فيه `M03_SPREADSHEET_ID` و`COMPANY_ID` (معرّف الشركة من النظام)، وشغّل `setupEmploymentApplication`.
3. خد لينك الاستمارة العام، وحطه في **التوظيف والمقابلات ← 📱 QR الاستمارة**.
4. اربط كارت «استمارة التقديم» بشيت M03، والـ Worker هيسحب الطلبات من غير تكرار.

## قواعد مهمة
- الأعمدة المحمية (المستلم، الحالة، تواريخ الدفع، الرصيد) **مش بتتنفذ من الشيت**. التعديل عليها بيتسجل «تعارض» والنظام بيرجّع قيمته.
- تعديل نفس السجل من الشيت والنظام في نفس الوقت = **تعارض للمراجعة**، مش آخر كتابة تكسب.
- ممنوع تحط كلمات مرور أو مفاتيح في أي شيت.
