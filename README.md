# IT Administration — النسخة الجديدة (it-administration-next)

## مكان الملفات
```
D:\IT_Administration_Project\
├─ source_archive\          الأرشيف الأصلي مفكوك كما هو (مرجع)
├─ master_package\          حزمة RC1: البرومبتات والمواصفات والقوالب
├─ baseline_app\            التطبيق الأصلي (للقراءة فقط، محدش يعدل عليه)
└─ it-administration-next\  ← هنا الشغل
   ├─ frontend\             الواجهة (مطوّرة من الأصل)
   ├─ backend\              السيرفر (FastAPI + SQLite)
   ├─ docs\                 AUDIT_ORIGINAL.md · ROADMAP.md
   ├─ setup.bat             تجهيز أول مرة
   ├─ run.bat               تشغيل النظام
   └─ run_tests.bat         تشغيل الاختبارات
```

## التشغيل
1. **أول مرة:** شغّل `setup.bat`. هيثبّت المكتبات ويطلب منك بيانات أول حساب **Super Admin**. كلمة المرور لازم تكون 10 حروف على الأقل، وفيها حروف وأرقام.
2. **كل مرة:** شغّل `run.bat`، والنظام هيفتح على `http://127.0.0.1:8000/it.html`.
3. توثيق الـ API بيفتح على `http://127.0.0.1:8000/api/docs`.

> **مهم (المرحلة الحالية):** شاشة الدخول في الواجهة لسه بتستخدم الحسابات التجريبية القديمة، والبيانات لسه في المتصفح. الحساب اللي بتعمله بـ `setup.bat` شغال على الـ Backend و`/api/docs` بس. ربط الاتنين ببعض هو **المرحلة 2**.

## اللي اتعمل لحد دلوقتي
- **Backend:**
  - دخول بجلسات آمنة: كوكي httpOnly بـ SameSite=Strict، والحساب بيتقفل بعد 5 محاولات غلط، ومفيش أي كلمة مرور افتراضية.
  - 7 أدوار (Super Admin، مدير IT، موظف IT، HR، المالية، الإدارة العليا، مخصص). الصلاحيات على السيرفر لكل وحدة وعملية، وبنطاق شركة/فرع/قسم.
  - موظف IT ومدير IT **ميشوفوش** البيانات الحساسة للموظفين، زي الرقم القومي والمرتب وتقييم HR.
  - إيقاف المستخدم بيلغي جلساته فورًا، ومينفعش النظام يفضل من غير Super Admin.
  - سجل تدقيق محمي: مفيش API تعدّله أو تمسحه، وكلمات المرور والأسرار بتتشال منه تلقائيًا.
  - مركز الربط فيه 14 كارت لـ Google Sheets/Forms/Drive وWE وغيرهم. **مفيش كارت بيتعرض «متصل»** غير بعد تحقق فعلي.
  - حماية CSRF، والسيرفر مش بيقدّم مجلد السكريبتات اللي فيه باسوردات WE.
- **الواجهة (M01):**
  - القائمة بقت 6 أقسام بس، وكلها قابلة للطي.
  - «دورة الموظف» بقت «رحلة الموظف».
  - المظهر بقى 3 حالات: حسب الجهاز، وفاتح، وغامق.
  - كل روابط الصفحات القديمة شغالة زي ما هي.
