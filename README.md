# IT Administration

نظام لإدارة قسم تقنية المعلومات لأكتر من شركة وفرع. فيه:
- الأصول والعهد.
- رحلة الموظف (التوظيف، والتعيين، والإخلاء).
- الخدمات التقنية والتجديدات.
- مصاريف ومشتريات IT.
- إدارة النظام، والربط مع Google Sheets أو Excel.

**الإصدار:** 1.1.0 · **الاختبارات:** 81 سيرفر + 42 صفحة متصفح، كلها ناجحة.

## التشغيل السريع (Windows)
1. ثبّت **Python 3.12**، وعلّم «Add to PATH».
2. شغّل `setup.bat`، وهيطلب منك تعمل حساب المدير.
3. شغّل `run.bat`، والنظام هيفتح على `http://127.0.0.1:8000/app.html`.
4. **اعمل نسخة من `backend\.env`**: فيه مفتاح تشفير الأسرار.

التفاصيل في [docs/README_DEPLOY_LOCAL.md](docs/README_DEPLOY_LOCAL.md). للنقل لـ VPS: [docs/README_DEPLOY_VPS.md](docs/README_DEPLOY_VPS.md).

## أهم المزايا
- **Dashboard رسمي:** الحرج أولًا، ومؤشرات ملوّنة، وعدّادات الجيجات (الأسوأ أولًا)، ورسوم الأصول والمصروف.
- **الأصول:**
  - أكواد `بادئة-فئة-تسلسل`، والسيريال فريد.
  - الحجز ≠ التسليم، وسجل حركات غير قابل للتعديل.
  - شاشات متعددة لكل جهاز.
  - تغيير الفئة.
  - **باسوردات الأجهزة مشفّرة**، تتسحب من Excel، وعرضها بصلاحية ومسجّل.
- **رحلة الموظف:**
  - مصفوفة القرار، والقرار النهائي في إيد HR بس.
  - 5 مستندات، والتجنيد مطلوب للذكور بس.
  - مهام IT: تنفيذ ← دليل ← اعتماد.
  - إقرارات بالإصدارات.
  - الإخلاء: تجميد فوري للعهدة، و6 جهات بالترتيب، والنسخة الورقية الموقعة.
- **الخدمات التقنية:**
  - شرائح مصر والسعودية (و«مع الوكيل»).
  - الإنترنت والأرضي بمدد مستقلة، وعتبات لكل خط.
  - مركز التجديدات، وتأكيد Backup واتساب، وربط إضافة WE.
- **المالية:**
  - اعتماد ورقي من الرئيس التنفيذي، واستلام جزئي.
  - فواتير ودفعات من غير دفع زيادة.
  - توزيع التكلفة مرة واحدة، والعملات منفصلة.
- **إدارة النظام:**
  - RBAC على السيرفر، وMFA، وCSRF، وCSP.
  - أسرار مشفّرة خارج المشروع، وسجل تدقيق مربوط بالـ hash.
  - نسخ احتياطي واستعادة متحقق منها، ومكتبة سكريبتات معتمدة.
- **البيانات:**
  - كل القوائم قابلة للتعديل.
  - استيراد وتصدير Excel لكل قسم.
  - ملف Excel محلي أو Google Sheet كمصدر بيانات.
  - القوالب الخمسة، ودباجة لكل شركة على المطبوعات.
